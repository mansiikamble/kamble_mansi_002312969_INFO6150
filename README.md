Assignment - 01

Welcome to my "Fashion Trends - Fall 24" Project.

It is an Online Magazine page for fashion enthusiast to explore what is hot and trending this season. The magazine gives an insight of the fashion world and keeps you updated about the upcoming trends and how people over the world are liking it.
This project is a simple demonstration of HTML and CSS functionalities. It highlights how to structure HTML page and apply styles with CSS.

•	Project Highlights :
HTML : Use of HTML elements and page structure.
CSS : Showcases advanced styling, including layouts and responsive design

•	Project Structure :
Assignment -01.html : The main html file containing core content and structure of web page.
style.css : The CSS file is responsible for all the styling, layouts, colour and fonts. 

•	This project also features 
1.Menu : It has a dropdown link that take you to new page which specifies about the future updates.

2.Contact US : This link takes you to a page containing contact details of the magazine company to help you get in direct contact with them via suitable platforms, such as telephone, email or mail.

3.Responsive Design : Adaptable layouts for different devices.

4.Custom Styling : Using CSS Unique design elements, including hover effects are added.

•	Below are the Tags used in the "Assignment -01.html" file
1.	header- It is used to add introductory content, or to add logos, navigation etc. here I have used the header to represent various introductory parts and navigations of website.
2.	Favicon - Favicon is an Icon used to represent a website in browser. In this website I have added a logo which reads 'InStyle' as a favicon, it represents the relation of website to the fashion styles.

3.	Table - Table structure is used in this website to show insights on popular brands. The aim is to help people to easily find the products which suits their fashion style and give the key description about the product. The tag helps present a data in tabular form which is feasible to users for comparison. 
4.	Form – This tag is used to create a form structure. which helps to get a response from user and gather the required data. We all have opinions that we would like to add and giving that platform to users helps the page to improve and grow to the liking of the people. It also helps to know what people would love to see in future content.
5.	Images – img tag is used to add an image in the webpage. Images are used to add a creative aspect to the website and make it interactive for user.
6.	Hyperlink - The tag is used to navigate from one page to another. It can link two web pages, Images 
7.	Button - It is used to add a clickable button to the website. In this Submit and Reset button is added at the end of the form to help user to either make changes or to submit the form. 
8.	audio - Tag is used to play an audio. In this I have attached a podcast audio which gives trendy ideas about outfits. 
9.	video – The tag is used to play the video. The video is about the wearable fall trends.  
10.	footer - It is added at the end of the content of the page. By positioning it at the desired position helps us give specific information at the end of the webpage.
11.	summary - This is added to provide a clear, accessible heading for the expandable content
12.	Tel - it is used to add telephone details in the Contact Us page 
13.	mailto - it is used to add email details in the Contact Us page
